My Dev Tools Vandalism

I used browser developer tools to temporarily "vandalize" a website. Below is a screenshot showing my changes. These edits only appeared on my computer and did not affect the actual website.

What I "Vandalized"

I made the following changes to the website using the browser's developer tools:

  • Changed the item listed on the apple product page for the Magic Mouse to The WORST mouse ever to be designed by Apple.
  • Replaced the main image with a humorous meme of the product via html.
  • Altered the background color to a vomit green color with the CSS background-color property.
  • Using the CSS font-size property to increase the size of the text.

This exercise was interesting because it allowed me to see how HTML and CSS work together to create a webpage. I found it amusing to change the product description and image to something humorous. Some changes worked as expected (changing the background color), while others required a bit of trial and error to get right (such as the link to the picture in the html code). Overall, I chose these changes because they were simple and demonstrated my use of developer tools. I now have a better understanding of how to use dev tools to experiment with web design and make temporary edits for testing or for fun. In my future web development projects, I will definitely use dev tools to see what works for other sites and use that knowledge to improve my own designs.
